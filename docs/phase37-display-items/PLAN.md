# Phase 37: 表示の項目（details・アラート・image）

## 課題

- md が苦手な人でも、文を折りたたんだり、注意書きを目立たせたりしたい
- 画像を項目として置き、大きさを決めたい（のちのギャラリーのページの土台にする）

## 方針

### details（折りたたみ）

```yaml
- details: 古い手順について # 見出し（押すと開閉する）
  text: |
    2025 年までの手順です。
- details: 詳しい設定
  items: # group と同じく項目を並べる
    - note: 管理者だけが使う
    - bat: setup.bat
```

- `text` は書いたままの文（改行もそのまま）。`items` は group と同じ。両方あれば text を先に出す
- 既定は枠を付けない。開いた中身の左に線を引いて範囲を示す。`frame: true` で枠で囲む
- `expanded: true` で開いた状態で出す（既定は閉じる）。開閉は覚えない。
  `open` は「ファイルを開く」の種類キーと重なるので使えない
- 入れ子は制限しない（details の中の details・group・buttons も置ける）。
  group の直下に group を置けないことと、buttons にボタンしか置けないことは今のまま

### アラート（md の記法と項目）

- md で GitHub の Alerts と同じ記法 `> [!NOTE]` などを使えるようにする（remark プラグインを足す）
- 種類は5つ。見出しはアイコンと文字を並べる。文字は日本語「メモ・ヒント・重要・警告・注意」、
  英語「Note・Tip・Important・Warning・Caution」（日本語は docs.github.com の日本語版の呼び方）
- 見た目は GitHub と同じにはせず、似た感じにする（色・アイコン・線は自前で決める）
- 項目としても書ける。本文は書いたままの文（装飾したいときは md に書く）

  ```yaml
  - note: これはメモ
  - important: これは重要
  ```

### image

```yaml
- image: launcher/img/構成図.png
  width: 300 # 数値は px、`50%` はページの幅に対する割合
  zoom: false # 押して拡大するのをやめる（既定は true）
```

- 表示できる画像は md と同じ（ランチャーのフォルダの中と `https`）
- 押すと、アプリのウィンドウの中で大きく出す。閉じるボタン・Esc・背景を押すで閉じる
- 動画は扱わない（外部への通信と CSP をゆるめることになるため。開くなら `url`・`open` で足りる）

## 決定事項ログ

### 2026-11-26: 足す項目と書き方

- details は `details: 見出し` に、`text`（書いたままの文）と `items`（group と同じ）の両方を書ける。
  md が苦手な人でも簡単に折りたためるように
- アラートは md の記法（GitHub の Alerts）と、`note:` などの項目の両方で書ける。
  見出しは GitHub のようにアイコンと文字を並べるが、見た目は似せるだけにする（そのまま写さない）
- image を押すと、別のアプリで開くのではなく、ウィンドウの中で拡大する。`zoom: false` で押せなくする。
  ギャラリーのページは別のフェーズで扱う
- 動画は扱わない

### 2026-11-26: details の入れ子と開閉

- 入れ子は制限しない。アプリの都合で要る制限（group の直下の group・buttons の中身）だけ残す
- 開閉は覚えない。`expanded: true` で最初から開いて出せる（`open` は種類キーと重なるため）

### 2026-11-26: details に枠を付けない

- 枠は付けず、開いた中身の左に線を引く。枠が要るときは group で囲む（キーは増やさない）
- よく見る折りたたみ（Notion・Confluence・GitHub の details）は枠なしで、枠は目立たせたいブロック（アラート）のものだから。
  group の中に置いたときに枠が二重にもならない

### 2026-11-26: details に frame: true を足す

- 枠で囲みたいときは `frame: true` と書く（ユーザーの要望）。group で囲むより短く、見出しも枠の中に入る
- 既定が枠なしなのは変えない
