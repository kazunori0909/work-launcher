# Phase 4: Info ページ

## 課題

- 案件の作業に関わる PC の情報（スペック・ドライブ・環境変数・ツールのバージョン）を、
  ランチャーからまとめて見られない

## 方針

### 範囲

- 組み込みの Info ページ（予約 ID `info`）を作る。まず Mac の情報を表示する。
  Windows で取り方が違う項目（GPU のドライバー・ドライブなど）は Windows 対応のときに足す
- 表示する項目（下の決定事項ログ）

### 構成

- 出力の読み取り（`sw_vers`・`vm_stat`・`mount`・`system_profiler`・ツールのバージョン）は
  `src/core/info.ts`（Electron 非依存、単体テスト付き）。コマンドの実行と集約は `src/main/info.ts`
- 画面は Info タブを開いたときに取りにいく（設定の読み込みとは別。ツールの確認に時間がかかるため）

## 決定事項ログ

### 2026-11-14: 表示する項目と更新・コピー

- 表示する項目（ユーザー判断）:
  - OS（名前・バージョン・ビルド・CPU アーキテクチャ）、コンピュータ名・ユーザー名
  - CPU（モデル・コア数）、メモリ（全体・使用中）
  - GPU。Mac はモデル・コア数・Metal のバージョン（Apple シリコンにはドライバーのバージョンが無いため）。
    Windows はドライバーのバージョンも出す（Windows 対応のときに作る）
  - ドライブ（ローカルとネットワーク。全体・空き）、IP アドレス（ネットワーク部品ごとの IPv4）
  - 設定した環境変数（`info.env`）、ツールのバージョン（`info.tools`）
  - WorkLauncher のバージョン（アプリ・Electron）
- 案: 起動してからの時間は入れない（ユーザー判断）
- 値はタブを開いたときに取る。タブ内に「更新」ボタンを置く（ユーザー判断）。自動更新はしない
- 内容をテキストでまとめてコピーするボタンを置く。問い合わせ・不具合の報告に貼り付けるため（ユーザー判断）

### 2026-11-14: Mac ではログインシェルの PATH を使う（Claude 提案）

- Finder やダブルクリックで起動したアプリの PATH は `/usr/bin:/bin:/usr/sbin:/sbin` 程度で、
  mise・Homebrew で入れたツールが見つからない（ターミナルから起動する開発中は気づかない）
- Mac では起動時にログインシェル（`$SHELL -ilc`）の PATH を読み、アプリの PATH に使う。
  Info のツールの確認だけでなく、`sh` 項目の実行にも効く。読めなければ元の PATH のまま

### 2026-11-14: 並べて表示し、アプリのバージョンはヘッダーへ

- スクロールを減らすため、システムとツールを横に並べる。ドライブと環境変数は幅いっぱいにする（ユーザー判断）
- ドライブは1つずつ小さな枠にして折り返す。Windows では C:・D:・E: など数が多くなるため（ユーザー判断）
- 狭いウィンドウでは縦1列に戻す（CSS grid の auto-fit。360px を下回ったら折り返す）
- WorkLauncher のバージョンはシステムの表から外し、ヘッダーの右端に常に出す（ユーザー判断）。
  フッターは画面の高さを使うため、ヘッダーにした。コピーのテキストには問い合わせ用に残す
- ログインシェルの PATH は、同じフォルダの重なりを取り除く（シェルが受け取った PATH にさらに足すため）
