# Phase 7: 設定フォルダを隠さない

## 課題

- 設定は `.launcher/` に置いている。`.` 始まりのフォルダは Mac の Finder では隠しファイルになり、
  非エンジニアが設定を直そうとしても置き場所が見えない（⌘⇧. を知らない人が多い）
- Windows のエクスプローラーは `.` 始まりを隠さないため、OS によって見え方が違う

## 方針

- 設定フォルダを `launcher/` に改名する。中の構成（config.yaml・pages・scripts・console・style）は変えない
- 公開前なので、旧名 `.launcher/` の互換（読み替え・移行の案内）は持たない
- 直すのは、コードの既定のパス・テスト・ヘルプ・docs/config.md・README・AGENTS.md・サンプル・.gitignore。
  完了済みフェーズの記録（phase1〜6 の PLAN.md など）は当時の記録なので直さない
- `work.launcher` の名前と、起動引数の `.launcher` 拡張子の見分けは変えない

## 決定事項ログ

### 2026-11-14: `.launcher/` を `launcher/` に改名する（ユーザー判断）

- 隠しフォルダをやめ、Mac でも Finder に出るようにする
- `.launcher/` にしたのは Phase 5 で、pages・scripts などがすでにそこにあったため（→ phase5 の PLAN.md）。
  リポジトリのルートを散らかさない意図もあったが、ポータブル版を同梱する使い方（→ phase6）では
  ランチャー専用のフォルダの中に置けるため、隠す理由が薄い
- 名前は `launcher/`。`work.launcher` と並べて対だと分かり、短い
- 案: `_launcher/`（一覧の先頭に来るが `_` がプログラマー寄り）・`settings/`（ランチャーのものと分からない）は採らない
- 弱点: 案件リポジトリの直下に置くと、案件側の同名フォルダとぶつかりうる
