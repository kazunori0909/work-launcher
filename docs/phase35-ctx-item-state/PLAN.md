# Phase 35: JS から項目の値と押せる・押せないを変える

## 課題

- select・radio・checkbox を変えたときに、関係するほかの項目の値を変えたい
- ボタンなどの項目を押せない・押せる状態に切り替えたい（処理の間はすべて押せなくする、など）
- いまの JS（`scripts`）は `ctx.select` で値を読むだけで、画面の状態は変えられない

## 方針

- `ctx` に3つの関数を足す。どれも Promise を返し、誤り（無い ID・選択肢に無い値）は例外にする
  - `ctx.set(id, value)` … select・radio・checkbox の値を変える。checkbox は `true` / `false` でも書ける
  - `ctx.reset(ids)` … select・radio・checkbox を初期値に戻す。`group` の ID なら中の項目、引数なしなら全部
  - `ctx.disable(id)` / `ctx.enable(id)` … 項目を押せなくする・押せるようにする。
    `id` は文字列か配列。引数なしなら全部の項目
- 状態はメインのセッション（ウィンドウごと）が持ち、変えたら画面へ送る（`project:state`）。
  読み込んだ案件（`ProjectView`）にも入れ、beforeOpen で変えた分も最初の画面に出す
- `ctx.set` は画面で変えたときと同じく選択肢にあるかを確かめ、`remember` なら記憶する。
  `await` したあとは、同じ関数の `ctx.select` と、そのあとに頼む動作の `${select:ID}` にも入る
- 指定する ID は、項目の `id`（ボタン・`group`・`buttons`）か、select の ID。
  `group`・`buttons` を指定すると中の項目もまとめて変える。同じ `id` の項目はページをまたいで全部変える
- 引数なしの `disable()`・`enable()` は「全部」だけを切り替え、ID で押せなくした分は保つ
- 押せない状態は、設定の読み直しでは保ち、案件を開き直したら戻す
- 画面の操作だけを止める。JS から `ctx.bat` などで呼ぶ動作は止めない
- 押せない状態は別の React の context で渡す（ヘルプの見本・サイトの体験ページは何も変えずに済む）

## 決定事項ログ

### 2026-11-23: JS から変える方法だけを入れる

- YAML で関係を書く案（`enabledWhen`・選択肢の `set:`）は、このフェーズでは入れない
- 理由: まず JS から変える仕組み（メインが状態を持ち、画面へ送る）を作る。YAML の案はその上に載せられる

### 2026-11-23: ctx.set では change を呼ばない

- 互いに書き換える項目どうしで、呼び出しが止まらなくなるのを避ける
- 続けて処理したいときは、その関数の中で続けて書く

### 2026-11-23: 名前は ctx.set・ctx.enable・ctx.disable

- `ctx.setSelect`・`ctx.setEnabled(id, bool)` も考えたが、短い方を選んだ
- 隠す機能（`ctx.hide` など）は入れない。押せなくするだけで足りる

### 2026-11-23: 引数なしの enable() は ID で押せなくした分を戻さない

- はじめは「全部を戻す」にしていたが、サンプルで処理の間だけ全部を止める（slowCount）と、
  チェックボックスで押せなくした項目まで押せるようになってしまった
- 処理の間だけ止めて元に戻す使い方を自然に書けるよう、`all` の切り替えだけにした

### 2026-11-24: 初期値に戻すのは ctx.reset を用意する

- 値を書かずに初期値へ戻したい（サンプルのリセットのボタンで、YAML の default を JS にも書いていた）
- `ctx.set(id, null)` のような「初期値を表す値」を渡す案は採らなかった。読んで意味が分かりにくく、選択肢の値とも紛れる
- `ctx.reset` なら `group` の ID でまとめて戻せる（`ctx.disable` と同じ指定のしかた）

### 2026-11-24: YAML だけでもリセットと押せる・押せないを書けるようにする

- 関数を書くのは利用者に手間なので、よく使う2つを YAML の指定でも書けるようにする（2026-11-23 の「JS だけ」を改める）
- `reset:` の項目を足す。値は ID か ID の並び（`ctx.reset` と同じ。`group` なら中の項目すべて）。
  見た目はほかのボタンと同じで、`label`・`icon`・`tooltip`・`confirm` も書ける
- `enabledWhen`・`disabledWhen` をすべての項目に書けるようにする（`group`・`buttons`・select 系も）
  - select の ID → 値の表。値の並びは「どれか」、キーを並べると「すべて」。checkbox は `true` / `false` でも書ける
  - 式は書けない（読み違いを避ける。複雑な条件は関数の `ctx.disable` で書く）
  - 両方を書けるが、1つの項目にはどちらか一方だけ
  - `ctx.disable` とはどちらかが押せなくすれば押せない。画面がいまの値から決めるので、メインに状態を持たない
- 隠す機能（`hiddenWhen`）は入れない。ボタンそのものを隠すのは管理者モードのような別の仕組みで考える
- 無い ID・選択肢に無い値は、読み込みでその項目をエラーにする
