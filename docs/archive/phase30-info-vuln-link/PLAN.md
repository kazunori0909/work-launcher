# Phase 30: Info から脆弱性の情報を調べられるようにする

## 課題

脆弱性への対応で、自分の PC のツールのバージョンに問題が無いかを確かめる場面が増えている。
Info でバージョンは見られるが、そこから脆弱性の情報を調べに行く手がかりが無い。

## 方針

Info のツールの枠に、脆弱性の情報のサイト（Cloudflare Radar の Zero Wire）へのリンクを1つ置く。
ユーザーが必要なときにそのページへ移り、自分で製品名を入れて調べる。
アプリからは問い合わせない（リンクは `openSchemes` を確かめて既定のブラウザで開く。ヘルプのリンクと同じ）。

## 決定事項ログ

### 2026-11-23: まずは Zero Wire のトップへのリンクだけを置く

- ツールの枠に https://radar.cloudflare.com/zero-wire へのリンクを置く。ツールが無いときも出す
- 採らなかった案:
  - アプリから NVD API に問い合わせて件数を出す: API キーは1人のメールアドレスに結びつき OSS に埋め込めない。
    キーなしの上限（30秒に5回）は会社のプロキシの内側では共有になる。CPE の対応づけの精度を確かめる手間もある
  - NVD の検索ページを、CPE・バージョン・重大度を入れた URL で開く
    （`cpeFilterMode=cpe&cpeName=…&cvssVersion=3.1&baseScoreMin=9&baseScoreMax=10`）:
    開けることと件数が API と合うことは確かめた。ただし画面の内部の引数で、予告なく変わりうる。いったん見送り
  - ツール名のキーワード検索の URL: 説明文の全文から探すので、java・php などは別の製品ばかりになる
- Zero Wire の一覧で、検索語を URL に入れて開けるかは確かめられていない（自動のブラウザはボット確認で止まる）
